## 1. 项目概述

### 1.1 项目背景

组织架构模块是企业级管理系统的核心基础模块，为系统提供用户身份管理、权限控制、组织结构管理等基础能力。几乎所有业务功能都依赖于组织架构模块提供的用户认证和权限校验服务。

### 1.2 业务目标

| 目标 | 说明 |
|------|------|
| 统一身份管理 | 提供用户的注册、登录、信息维护全生命周期管理 |
| 细粒度权限控制 | 基于RBAC模型，支持角色-菜单-权限三级控制体系 |
| 组织架构管理 | 支持多级部门树管理，灵活调整组织结构 |
| 操作审计 | 完整记录用户操作日志，支持安全审计 |
| 可配置性 | 系统配置支持动态调整，无需重启服务 |

### 1.3 功能范围

本模块覆盖以下8个功能子模块：

- **用户管理** — 用户CRUD、批量导入导出、状态管理、密码重置
- **用户个人中心** — 登录注册、个人信息维护、安全设置
- **角色管理** — 角色CRUD、菜单权限分配、用户分配、拖拽排序
- **菜单管理** — 菜单CRUD、树形结构、拖拽排序、启用/禁用
- **权限管理** — 权限标识CRUD、菜单绑定、拖拽排序
- **部门管理** — 部门CRUD、树形结构、负责人管理、拖拽排序
- **日志管理** — 操作日志查询、导出、详情追溯
- **系统配置** — 动态配置项管理、拖拽排序

### 2.3 分层架构设计

采用**四层架构**，各层职责明确：

```
┌─────────────────────────────────────┐
│         View Layer (视图层)           │
│   - 接收HTTP请求、参数校验、响应输出    │
│   - 继承通用ModelViewSet基类           │
│   - 无业务逻辑                        │
├─────────────────────────────────────┤
│         Service Layer (服务层)         │
│   - 核心业务逻辑                      │
│   - 事务管理                         │
│   - 跨模型操作                        │
│   - 可复用/可测试                     │
├─────────────────────────────────────┤
│      Serializer Layer (序列化层)       │
│   - 输入校验 (validate_*)             │
│   - 数据转换 (to_representation)      │
│   - 嵌套序列化                        │
├─────────────────────────────────────┤
│         Model Layer (模型层)           │
│   - 数据定义 (字段/关系/索引)          │
│   - 基础业务约束 (unique/choices)     │
│   - 信号处理 (signal)                 │
└─────────────────────────────────────┘
```

## 3. 数据库设计

### 3.1 设计原则

1. **统一字符集**：所有表使用 `utf8mb4` 字符集 + `utf8mb4_unicode_ci` 排序规则，全面支持emoji和特殊字符
2. **统一存储引擎**：全部使用 `InnoDB`，支持事务和外键
3. **主键策略**：所有表使用 `INT AUTO_INCREMENT` 自增主键（单表数据量可控），大表(日志)使用 `BIGINT`
4. **时间字段**：统一 `create_time` + `modify_time` 模式，`modify_time` 设置为 `ON UPDATE CURRENT_TIMESTAMP`
5. **软删除 vs 硬删除**：用户表使用 `status` 字段逻辑禁用，日志表记录物理保留
6. **排序字段索引**：所有 `sort_order` 字段单独建立索引
7. **关联表不使用自增主键**：使用复合唯一约束替代

```sql
    `password`     varchar(255)  not null                    comment '密码（bcrypt加密存储）',
    `nickname`     varchar(100)  default ''                  comment '昵称',
    `real_name`    varchar(100)  default ''                  comment '真实姓名',

    `email`        varchar(128)  default ''                  comment '邮箱',

    `avatar`       varchar(512)  default ''                  comment '头像URL',
    `status`       tinyint       default 1                   comment '状态（1启用 0禁用）',
    `remark`       varchar(255)  default ''                  comment '备注',
    `last_login_ip`   varchar(64)   default ''               comment '最后登录IP',
```

### 3.4 排序策略设计

#### 3.4.1 排序字段使用矩阵

| 表名 | 排序字段 | 排序范围 | 排序SQL | 应用场景 |
|------|---------|---------|---------|---------|
| `sys_role` | `sort_order` | 全局 | `ORDER BY sort_order ASC, id ASC` | 角色列表展示顺序 |
| `sys_menu` | `sort_order` | 同级菜单 | `ORDER BY parent_id, sort_order ASC, id ASC` | 侧边栏菜单排序 |
| `sys_permission` | `sort_order` | 全局 | `ORDER BY sort_order ASC, id ASC` | 权限列表展示顺序 |
| `sys_department` | `sort_order` | 同级部门 | `ORDER BY parent_id, sort_order ASC, id ASC` | 组织树节点排序 |
| `sys_config` | `sort_order` | 全局 | `ORDER BY sort_order ASC, id ASC` | 配置列表展示顺序 |
| `sys_user` | 无 | — | `ORDER BY create_time DESC` | 按创建时间倒序 |
| `sys_log` | 无 | — | `ORDER BY create_time DESC` | 按操作时间倒序 |

#### 3.4.2 排序值更新策略

- **单个更新**：指定ID + 新的 `sort_order` 值
- **批量拖拽更新**：前端拖拽完成后，提交排序数组 `[{id: 1, sort_order: 0}, {id: 2, sort_order: 1}, ...]`
- **新增默认**：新记录默认 `sort_order = 0`，可通过初始化脚本设为当前最大值+1
- **排序间隔**：推荐使用步长 `10`（0, 10, 20, ...），方便中间插入而不需全部重排

### 4.3 接口权限校验实现

#### 后端权限校验方式

```python
# 方式一：基于权限标识的装饰器
from rest_framework.permissions import BasePermission

class HasPermission(BasePermission):
    """校验用户是否拥有指定权限标识"""
    
    def __init__(self, permission_code: str):
        self.permission_code = permission_code
    
    def has_permission(self, request, view):
        if not request.user or not request.user.is_authenticated:
            return False
        # 超级管理员放行
        if request.user.is_superuser:
            return True
        # 检查权限标识
        return request.user.has_permission(self.permission_code)


# 方式二：ViewSet级别配置
class UserViewSet(ModelViewSet):
    permission_classes = [IsAuthenticated]
    
    def get_permissions(self):
        if self.action == 'destroy':
            return [HasPermission('user:delete')]
        return super().get_permissions()
```

### 4.4 前端权限控制

```typescript
// 路由级权限：动态路由
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router'
import { useAuthStore } from '@/store/auth'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/login', component: () => import('@/views/login/Login.vue') },
    { path: '/', redirect: '/dashboard' },
    // 动态路由在登录后根据菜单数据生成
  ]
})

router.beforeEach(async (to, from, next) => {
  const authStore = useAuthStore()
  if (!authStore.token && to.path !== '/login') {
    return next('/login')
  }
  // 动态路由尚未加载时初始化
  if (authStore.token && !authStore.dynamicRoutesLoaded) {
    await authStore.generateDynamicRoutes()
    next(to.path) // 重新导航
    return
  }
  next()
})


// 按钮级权限：自定义指令
// directives/permission.ts
import { useAuthStore } from '@/store/auth'

export const vPermission = {
  mounted(el: HTMLElement, binding: DirectiveBinding) {
    const { value } = binding
    const authStore = useAuthStore()
    if (value && !authStore.hasPermission(value)) {
      el.parentNode?.removeChild(el)
    }
  }
}
```

#### 5.0.2 认证流程

```
┌──────────┐     POST /api/user/login      ┌──────────┐
│  前端     │ ──────────────────────────────→ │  后端     │
│  (Vue3)  │ ←────────────────────────────── │  (DRF)   │
└──────────┘   { access_token, refresh_token } └──────────┘
      │
      │  后续所有请求携带 Header:
      │  Authorization: Bearer <access_token>
      │
      ├── access_token 有效 ──→ 正常请求
      │
      ├── access_token 过期 ──→ 返回 401, code=3001
      │       │
      │       └──→ 前端自动调用 POST /api/user/refresh-token
      │            ├── 成功 → 替换 token，重试原请求
      │            └── 失败 → 清除本地 token，跳转 /login
```

| 场景 | HTTP 状态码 | 业务码 | 前端处理 |
|------|------------|--------|---------|
| Token 缺失 | 401 | 3000 | 清除 token，跳转登录页 |
| Token 过期 | 401 | 3001 | 自动刷新 token，失败则跳转登录页 |
| Token 无效 | 401 | 3002 | 清除 token，跳转登录页 |
| 无权限操作 | 403 | 3003 | 提示"无操作权限"，不跳转 |

> **前端注意**：建议在 axios 拦截器中统一处理以上四种情况，业务代码无需重复判断。

## 6. 业务逻辑详细设计

### 6.1 用户管理业务逻辑

```
新增用户流程：
  1. 参数校验（用户名唯一、邮箱格式、手机号格式）
  2. 密码加密（bcrypt）
  3. 用户基础信息入库
  4. 分配角色（写入 sys_user_role_relation）
  5. 记录操作日志
  6. 返回用户信息

更新用户流程：
  1. 验证用户是否存在
  2. 校验字段唯一性（排除自身）
  3. 更新基础信息
  4. 更新角色关联（先删后加）
  5. 记录操作日志

删除用户流程：
  1. 检查是否为超级管理员（禁止删除）
  2. 物理删除或逻辑禁用
  3. 级联删除用户-角色关联（外键自动处理）
  4. 记录操作日志

重置密码流程：
  1. 验证操作者权限
  2. 生成随机密码或使用默认密码
  3. bcrypt加密后更新
  4. 返回新密码（管理员可见）
```

### 6.2 角色-权限分配逻辑

```
分配菜单权限（核心业务逻辑）：
  1. 验证角色存在且非系统内置角色（内置角色不可修改）
  2. 获取前端提交的菜单ID列表
  3. 校验菜单ID全部有效（避免脏数据）
  4. 开启事务：
     a. 删除原有关联 sys_role_menu_relation
     b. 批量插入新关联
  5. 提交事务
  6. 清除该角色的权限缓存
  7. 记录操作日志

注意：
  - 当菜单是目录类型(menu_type=0)时，如果勾选目录，自动级联勾选其所有子菜单（前端实现）
  - 当取消某个菜单时，如果父菜单下没有其他子菜单被勾选，父菜单应自动取消（前端实现）
```

### 6.3 菜单树构建逻辑

```python
def build_menu_tree(menus: List[dict], parent_id: int = 0) -> List[dict]:
    """
    递归构建菜单树
    - 从根节点(parent_id=0)开始
    - 按 sort_order 排序同级节点
    - 递归构建每个节点的children
    """
    tree = []
    for menu in menus:
        if menu['parent_id'] == parent_id:
            children = build_menu_tree(menus, menu['id'])
            if children:
                menu['children'] = children
            else:
                menu['children'] = []
            tree.append(menu)
    tree.sort(key=lambda x: x['sort_order'])
    return tree
```

**前端获取菜单树时机**：

```
用户登录成功
    │
    ▼
获取用户信息接口（返回角色和权限列表）
    │
    ▼
调用 /api/menu/tree 获取完整菜单树（根据角色过滤）
    │
    ▼
前端递归构建动态路由
    │
    ▼
添加到 Vue Router
```

### 6.4 部门树构建逻辑

与菜单树类似，按 `parent_id` 和 `sort_order` 递归构建。区别：

- 部门树通常用于选择归属部门，需要保留所有节点
- 数据隔离场景下，不同角色可见不同部门树（如普通管理员只能看到本部门及以下）

### 6.5 拖拽排序实现逻辑

```
前端拖拽交互流程：
  1. 用户长按并拖拽行/节点到新位置
  2. SortableJS 更新DOM顺序（实时反馈）
  3. 拖拽完成后，遍历当前排序结果
  4. 构建批量排序数据：[{id, sortOrder}, ...]
  5. 调用 POST /api/{module}/batch-sort 接口
  6. 后端接收数组，逐个更新 sort_order

后端批量排序：
  def batch_sort(model_class, sort_data: List[dict]):
      """
      sort_data: [{"id": 1, "sort_order": 0}, ...]
      使用 bulk_update 批量一次性提交
      """
      instances = []
      for item in sort_data:
          instance = model_class(id=item['id'], sort_order=item['sort_order'])
          instances.append(instance)
      model_class.objects.bulk_update(instances, ['sort_order'])
```

### 6.7 操作日志记录逻辑

采用 **Django Middleware + 装饰器** 双模式：

```python
# 方式一：Middleware自动记录（推荐用于CRUD操作）
class OperationLogMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response
    
    def __call__(self, request):
        # 记录请求开始时间
        start_time = time.time()
        
        response = self.get_response(request)
        
        # 计算耗时
        duration = int((time.time() - start_time) * 1000)
        
        # 跳过静态文件和不需要记录的路径
        if self._should_skip(request.path):
            return response
        
        # 异步记录日志
        self._record_log(request, response, duration)
        
        return response
    
    def _record_log(self, request, response, duration):
        # 提取用户信息
        user = getattr(request, 'user', None)
        # 提取请求参数（脱敏处理）
        params = self._safe_params(request)
        
        Log.objects.create(
            user_id=user.id if user and user.is_authenticated else None,
            username=user.username if user and user.is_authenticated else '',
            module=self._get_module(request.path),
            operation=self._get_operation(request.method),
            request_url=request.path,
            request_method=request.method,
            request_params=params,
            ip=self._get_client_ip(request),
            user_agent=request.META.get('HTTP_USER_AGENT', ''),
            duration=duration,
            status=1 if 200 <= response.status_code < 300 else 0,
        )


# 方式二：手动装饰器记录（用于特殊操作）
def log_operation(module: str, operation: str):
    def decorator(view_func):
        @wraps(view_func)
        def wrapper(request, *args, **kwargs):
            return view_func(request, *args, **kwargs)
        return wrapper
    return decorator
```

#### 8.1.3 树结构构建工具

```python
# utils/tree.py
from typing import List, Dict, Any, Optional, Callable


def build_tree(
    items: List[Dict[str, Any]],
    parent_id: int = 0,
    id_field: str = 'id',
    parent_field: str = 'parent_id',
    children_field: str = 'children',
    sort_field: Optional[str] = 'sort_order',
) -> List[Dict[str, Any]]:
    """
    通用树结构构建函数
    
    :param items: 扁平数据列表
    :param parent_id: 父节点ID
    :param id_field: ID字段名
    :param parent_field: 父ID字段名
    :param children_field: 子节点字段名
    :param sort_field: 排序字段名（None表示不排序）
    :return: 树形结构
    """
    tree = []
    for item in items:
        if item.get(parent_field) == parent_id:
            children = build_tree(
                items, item.get(id_field),
                id_field, parent_field, children_field, sort_field
            )
            if children:
                item[children_field] = children
            else:
                item[children_field] = []
            tree.append(item)
    
    if sort_field:
        tree.sort(key=lambda x: x.get(sort_field, 0))
    
    return tree


def flatten_tree(
    tree: List[Dict[str, Any]],
    children_field: str = 'children',
) -> List[Dict[str, Any]]:
    """
    将树形结构展平为列表
    
    :param tree: 树形数据
    :param children_field: 子节点字段名
    :return: 扁平列表
    """
    result = []
    for node in tree:
        children = node.pop(children_field, [])
        result.append(node)
        result.extend(flatten_tree(children, children_field))
    return result
```

```python
        # 生成JWT Token
        refresh = RefreshToken.for_user(user)
        
        # 更新最后登录信息
        user.last_login_time = timezone.now()
        user.save(update_fields=['last_login_time'])
        
        # 获取角色和权限
        roles = user.roles.all()
        permissions = self._get_user_permissions(user)
        
        return {
            'access_token': str(refresh.access_token),
            'refresh_token': str(refresh),
            'user': {
                'id': user.id,
                'username': user.username,
                'nickname': user.nickname,
                'avatar': user.avatar,
                'roles': [r.role_code for r in roles],
                'permissions': list(permissions),
            }
        }
    
    @transaction.atomic
    def create_user(self, data):
        """创建用户（事务保护）"""
        password = data.pop('password', '123456')
        role_ids = data.pop('role_ids', [])
        
        # 加密密码
        data['password'] = make_password(password)
        
        # 创建用户
        user = User.objects.create(**data)
        
        # 分配角色
        if role_ids:
            relations = [UserRoleRelation(user_id=user.id, role_id=rid) for rid in role_ids]
            UserRoleRelation.objects.bulk_create(relations)
        
        return user
    
    @transaction.atomic
    def update_user(self, user, data):
        """更新用户"""
        role_ids = data.pop('role_ids', None)
        
        # 更新基本信息
        for key, value in data.items():
            setattr(user, key, value)
        user.save()
        
        # 更新角色
        if role_ids is not None:
            UserRoleRelation.objects.filter(user_id=user.id).delete()
            if role_ids:
                relations = [UserRoleRelation(user_id=user.id, role_id=rid) for rid in role_ids]
                UserRoleRelation.objects.bulk_create(relations)
        
        return user
    
    def delete_user(self, user):
        """删除用户"""
        user.delete()
    
    def batch_delete_users(self, ids):
        """批量删除用户"""
        # 排除超级管理员
        User.objects.filter(id__in=ids).exclude(username='admin').delete()
    
    def get_user_list(self, keyword='', status=None, dept_id=None):
        """获取用户列表（带条件筛选）"""
        queryset = User.objects.select_related('department').prefetch_related('roles').all()
        
        if keyword:
            queryset = queryset.filter(
                Q(username__icontains=keyword) |
                Q(nickname__icontains=keyword) |
                Q(real_name__icontains=keyword) |
                Q(email__icontains=keyword) |
                Q(telephone__icontains=keyword)
            )
        if status is not None:
            queryset = queryset.filter(status=status)
        if dept_id:
            # 包含子部门
            dept_ids = get_sub_department_ids(dept_id)
            queryset = queryset.filter(department_id__in=dept_ids)
        
        return queryset.order_by('-create_time')
    
    def _get_user_permissions(self, user):
        """获取用户所有权限标识（去重）"""
        return Permission.objects.filter(
            menu__role__user=user
        ).values_list('permission_code', flat=True).distinct()
```

```python
# utils/excel.py
import io
import openpyxl
from openpyxl.styles import Font, Alignment, PatternFill
from django.http import HttpResponse


class ExcelHandler:
    """Excel导入导出通用处理器"""
    
    def export(self, filename: str, headers: list, keys: list, data: list[dict]) -> HttpResponse:
        """
        导出Excel
        
        :param filename: 文件名（不含扩展名）
        :param headers: 表头列表 ['用户名', '邮箱', ...]
        :param keys: 数据键名 ['username', 'email', ...]
        :param data: 数据列表 [{'username': 'admin', ...}, ...]
        """
        wb = openpyxl.Workbook()
        ws = wb.active
        ws.title = filename
        
        # 写入表头
        header_fill = PatternFill(start_color='4472C4', end_color='4472C4', fill_type='solid')
        header_font = Font(color='FFFFFF', bold=True, size=11)
        
        for col, header in enumerate(headers, 1):
            cell = ws.cell(row=1, column=col, value=header)
            cell.fill = header_fill
            cell.font = header_font
            cell.alignment = Alignment(horizontal='center')
        
        # 写入数据
        for row_idx, item in enumerate(data, 2):
            for col_idx, key in enumerate(keys, 1):
                value = item.get(key, '')
                # 处理嵌套字段
                if isinstance(value, list):
                    value = ', '.join(str(v) for v in value)
                ws.cell(row=row_idx, column=col_idx, value=value)
        
        # 自适应列宽
        for col in ws.columns:
            max_length = 0
            col_letter = col[0].column_letter
            for cell in col:
                if cell.value:
                    max_length = max(max_length, len(str(cell.value)))
            ws.column_dimensions[col_letter].width = min(max_length + 4, 50)
        
        # 构建响应
        response = HttpResponse(
            content_type='application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
        )
        response['Content-Disposition'] = f'attachment; filename="{filename}.xlsx"'
        wb.save(response)
        return response
    
    def import_data(self, file, required_fields: list, field_map: dict, process_func):
        """
        导入Excel
        
        :param file: 上传的文件对象
        :param required_fields: 必填字段列表
        :param field_map: 列名映射 {'Excel列名': '字段名'}
        :param process_func: 单行处理函数，接收dict，返回 str（空字符串表示成功，否则为错误信息）
        :return: {'total': int, 'success': int, 'failure': int, 'errors': list}
        """
        wb = openpyxl.load_workbook(file)
        ws = wb.active
        
        # 读取表头
        headers = [cell.value for cell in ws[1]]
        
        # 构建字段索引映射
        col_map = {}
        for col_idx, header in enumerate(headers):
            if header in field_map:
                col_map[col_idx] = field_map[header]
        
        result = {
            'total': 0,
            'success': 0,
            'failure': 0,
            'errors': [],
        }
        
        # 逐行读取
        for row_idx, row in enumerate(ws.iter_rows(min_row=2, values_only=True), 2):
            result['total'] += 1
            
            # 跳过空行
            if all(cell is None for cell in row):
                result['total'] -= 1
                continue
            
            # 构建数据字典
            data = {}
            for col_idx, field in col_map.items():
                if col_idx < len(row):
                    data[field] = row[col_idx]
            
            # 检查必填字段
            missing = [f for f in required_fields if not data.get(f)]
            if missing:
                result['failure'] += 1
                result['errors'].append({
                    'row': row_idx,
                    'message': f"缺少必填字段: {', '.join(missing)}"
                })
                continue
            
            # 执行导入
            try:
                error = process_func(data)
                if error:
                    result['failure'] += 1
                    result['errors'].append({'row': row_idx, 'message': error})
                else:
                    result['success'] += 1
            except Exception as e:
                result['failure'] += 1
                result['errors'].append({'row': row_idx, 'message': str(e)})
        
        return result
```

```python
# 密码强度校验
import re

def validate_password_strength(password: str) -> tuple[bool, str]:
    if len(password) < 6:
        return False, '密码长度不能少于6位'
    if not re.search(r'[A-Za-z]', password):
        return False, '密码必须包含字母'
    if not re.search(r'\d', password):
        return False, '密码必须包含数字'
    return True, ''
```

```typescript
// 敏感信息脱敏工具
// utils/sanitize.ts
export function sanitizeParams(params: Record<string, any>): Record<string, any> {
  const sensitiveFields = ['password', 'token', 'authorization', 'secret']
  const sanitized = { ...params }
  
  for (const key of Object.keys(sanitized)) {
    if (sensitiveFields.some(f => key.toLowerCase().includes(f))) {
      sanitized[key] = '******'
    }
  }
  return sanitized
}
```
